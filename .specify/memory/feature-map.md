Rules: features execute in order; a feature is done when tasks are checked, tests green,
and both locales verified. Contract updates land only via the doc 16 §3 adoption flow.

**Slices vs umbrella.** `005 public-pages` is the roadmap umbrella for the remaining public pages and
stays OPEN. Its Projects P1 slice shipped under `005-public-pages`; subsequent Profile slices get
their own SpecKit identity (008 = Experience, 009 = About; Resume and the integrated Profile
verification follow). Completing a slice never marks the umbrella done. The `005` spec's line "No Feature 008
exists" was scoped to the Projects slice and is superseded for later slices by the owner's
2026-07-29 directive.
